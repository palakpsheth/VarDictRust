**Goal:** Package and distribute VarDictRust on Bioconda under the official package name `vardictrust` (`conda install -c bioconda -c conda-forge vardictrust`), with a hardened in-tree recipe, automated recipe validation, test fixtures, submission helper scripts, and documentation updates.

**Architecture:** Maintain a canonical Bioconda recipe under `packaging/bioconda/recipes/vardictrust/` within the repository. Provide local verification through `harness/tests/test_bioconda_recipe.py` (discovered automatically by `harness/run_self_tests.sh`) and containerized build testing via `harness/test_bioconda_recipe.sh`. Automate synchronization to `bioconda/bioconda-recipes` via `packaging/bioconda/prepare_bioconda_pr.sh`. Update `README.md`, `CHANGELOG.md`, `docs/ecosystem-survey.md`, and `CONTRIBUTING.md`.

**Tech Stack:** Conda / Bioconda (`conda-build`, `bioconda-utils`), Rust / Cargo (`cargo-bundle-licenses`), Python 3 (strict standard library only), Bash, GitHub Actions.

**Spec:** Follows official Bioconda guidelines for Rust packages, Conda recipe specifications (meta.yaml Jinja2 format), and the rewrites.bio distribution manifesto.

## Global Constraints & Hardened Invariants

- Package name on Bioconda MUST be `vardictrust` (binary produced: `vardictrust`).
- Zero changes to engine code (`crates/vardictrust-core`).
- Python test files in `harness/tests/` MUST depend exclusively on the Python Standard Library per `harness/tests/test_stdlib_purity.py`.
- **Conda Sandboxing Guard:** `build.sh` MUST explicitly set `CARGO_HOME="${SRC_DIR}/.cargo"` and `CARGO_NET_GIT_FETCH_WITH_CLI=true`, and clean up `rm -rf "$CARGO_HOME"` before completion to prevent bloat.
- **Modern Conda-Build Standards:** `meta.yaml` MUST include `{{ stdlib('c') }}` alongside `{{ compiler('c') }}` and `{{ compiler('rust') }}` (CEP 13 requirement).
- **No Bogus `run_exports`:** Standalone CLI tools must not declare `run_exports` (reserved for C/C++ shared libraries).
- **Multi-Platform Support:** Add `extra.additional-platforms: [linux-aarch64, osx-arm64]`.
- **License Completeness:** Declared license is `MIT AND GPL-2.0-or-later` (due to ported R `nmath` routines documented in `LICENSE-3RD-PARTY`). `license_file` MUST catalog `LICENSE`, `LICENSE-3RD-PARTY`, and `THIRDPARTY.yml` (generated by `cargo-bundle-licenses`).
- **Zero-Tolerance Integrity (Rule 0/0b):** `prepare_bioconda_pr.sh` MUST fail hard if GitHub release archive is unreachable (never fall back to diverging local `git archive`). `harness/test_bioconda_recipe.sh` must execute real checks and never mock-echo success.

```bash
#!/usr/bin/env bash
set -euo pipefail

# Conda-build sandboxing:
# Conda-build strips or randomizes HOME, which breaks default Cargo paths (~/.cargo).
# Explicitly anchor CARGO_HOME to the source build directory.
export CARGO_HOME="${SRC_DIR:-$(pwd)}/.cargo"
export CARGO_NET_GIT_FETCH_WITH_CLI=true
export RUST_BACKTRACE=1

# Bundle third-party licenses required by Bioconda and Conda-Forge policies
cargo-bundle-licenses --format yaml --output THIRDPARTY.yml

# Install the binary into conda prefix bin
cargo install --no-track --locked --verbose --root "${PREFIX}" --path crates/vardictrust

# Clean up temporary cargo cache and install records to prevent bloat
rm -rf "$CARGO_HOME"
rm -f "${PREFIX}/.crates.toml" "${PREFIX}/.crates2.json"
```

### Task 5: Hardened Bioconda Submission Automation Helper

**Files:**

**Interfaces:**
- Consumes: Release tag version (e.g. `1.0.0`), GitHub release tarball URL

- [x] **Step 1: Write `packaging/bioconda/prepare_bioconda_pr.sh`**

```bash
#!/usr/bin/env bash
# =============================================================================
# packaging/bioconda/prepare_bioconda_pr.sh
# Automates preparing a pull request to github.com/bioconda/bioconda-recipes.
# Computes the release tarball SHA256 checksum and updates meta.yaml.
# Fails loudly per Rule 0/0b if the tag does not exist on GitHub.
# =============================================================================
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
ROOT_DIR="$(cd "$SCRIPT_DIR/../.." && pwd)"
RECIPE_DIR="$SCRIPT_DIR/recipes/vardictrust"
META_YAML="$RECIPE_DIR/meta.yaml"

VERSION="${1:-1.0.0}"
TARBALL_URL="https://github.com/palakpsheth/VarDictRust/archive/refs/tags/v${VERSION}.tar.gz"

echo "Preparing Bioconda recipe for VarDictRust v${VERSION}..."
echo "Fetching release tarball from GitHub: ${TARBALL_URL}"

TMP_DIR="$(mktemp -d)"
trap 'rm -rf "$TMP_DIR"' EXIT

if ! curl -LsSf "$TARBALL_URL" -o "$TMP_DIR/release.tar.gz"; then
  echo "================================================================================" >&2
  echo "ERROR: Could not fetch release tarball from GitHub!" >&2
  echo "URL: $TARBALL_URL" >&2
  echo "Per Rule 0b: We NEVER use a local git archive fallback because local gzip" >&2
  echo "compression produces a different SHA256 than GitHub's release tarball." >&2
  echo "Action: Ensure tag v${VERSION} is pushed to GitHub before preparing Bioconda PR:" >&2
  echo "  git push origin v${VERSION}" >&2
  echo "================================================================================" >&2
  exit 1
fi

SHA256="$(sha256sum "$TMP_DIR/release.tar.gz" | awk '{print $1}')"
echo "Computed live GitHub release SHA256: ${SHA256}"

# Update sha256 in meta.yaml
sed -i -E "s/sha256: [0-9a-fA-F]+/sha256: ${SHA256}/" "$META_YAML"
sed -i -E "s/\{% set version = \".*\" %\}/{% set version = \"${VERSION}\" %}/" "$META_YAML"

echo "Updated $META_YAML with version ${VERSION} and sha256 ${SHA256}."
echo ""
echo "Next steps to publish on Bioconda:"
echo "1. Fork https://github.com/bioconda/bioconda-recipes"
echo "2. Clone your fork: git clone git@github.com:<your-user>/bioconda-recipes.git"
echo "3. Branch: cd bioconda-recipes && git checkout -b add-vardictrust"
echo "4. Copy recipe: cp -r $RECIPE_DIR recipes/vardictrust"
echo "5. Commit: git add recipes/vardictrust && git commit -m 'add vardictrust ${VERSION}'"
echo "6. Push and PR: git push origin add-vardictrust and open PR against master"
echo "7. Comment '@BiocondaBot please build' and await human review from @bioconda/core"
```
