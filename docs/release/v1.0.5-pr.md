## Key Additions, Optimizations & Fixes in `v1.0.5`

### 1. Full-Genome GIAB HG002 `chr1..chr22` Parity (`8,111,171` Variants, [Issue #47](https://github.com/palakpsheth/VarDictRust/issues/47) / [PR #48](https://github.com/palakpsheth/VarDictRust/pull/48))
- **Soft-Clip `unused` State Preservation & `find_conseq` Sync in `find_sv` ([`crates/vardictrust-core/src/sv.rs`](../../crates/vardictrust-core/src/sv.rs)):**
  - Preserves `sclip.used` across candidate `<DEL>`, `<DUP>`, and `<INV>` checks when no structural variant is finalized, and synchronizes `find_conseq` soft-clip mutations back to the live `Sclip` map via `sync_sclip_after_conseq` (`StructuralVariantsProcessor.java:687–965`).
- **Reference Seed Extension Parameter `-x` vs `-X` ([`crates/vardictrust-core/src/reference.rs`](../../crates/vardictrust-core/src/reference.rs)):**
  - Uses `config.extension` (`-x`, default `0`) instead of `config.extension_nuc` (`-X`, default `3`) when computing reference seed fetch bounds in `get_reference` (`ReferenceResource.java:85–89`), with checked/saturating arithmetic in `SeedMap`.

### 2. Hot-Path Realignment, CRAM Streaming & Runner Optimizations ([Issue #45](https://github.com/palakpsheth/VarDictRust/issues/45), [PR #46](https://github.com/palakpsheth/VarDictRust/pull/46), [PR #49](https://github.com/palakpsheth/VarDictRust/pull/49))
- **SWAR `u64` `find_35_match` ([`crates/vardictrust-core/src/realign.rs`](../../crates/vardictrust-core/src/realign.rs)):**
  - Accelerates $3'/5'$ soft-clip sequence matching via 8-byte little-endian `u64` XOR + zero-byte detection before tail byte checks.
- **Streaming Cached CRAM Container Decoding ([`crates/vardictrust-core/src/bam.rs`](../../crates/vardictrust-core/src/bam.rs)):**
  - Streams decoded CRAM records directly from cached containers without materializing intermediate per-slice record vectors, and eliminates redundant `stat()` syscalls on BAM metadata cache hits.
- **Single-Allele Somatic `Vars` Borrowing & Synchronous 1-Thread Fast-Path ([`crates/vardictrust-core/src/postprocess/somatic.rs`](../../crates/vardictrust-core/src/postprocess/somatic.rs), [`src/runner.rs`](../../crates/vardictrust-core/src/runner.rs)):**
  - Avoids cloning `Variant` structs on single-allele somatic loci and bypasses Rayon thread-pool dispatch when `num_threads == 1`.
