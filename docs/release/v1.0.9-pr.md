## Overview

This pull request prepares and certifies **VarDictRust `v1.0.9`** off `main` (`0f752f0`), consolidating 13 pull requests ([PR #110](https://github.com/palakpsheth/VarDictRust/pull/110)–[PR #112](https://github.com/palakpsheth/VarDictRust/pull/112), [PR #115](https://github.com/palakpsheth/VarDictRust/pull/115), [PR #117](https://github.com/palakpsheth/VarDictRust/pull/117), [PR #119](https://github.com/palakpsheth/VarDictRust/pull/119)–[PR #122](https://github.com/palakpsheth/VarDictRust/pull/122), [PR #124](https://github.com/palakpsheth/VarDictRust/pull/124), [PR #129](https://github.com/palakpsheth/VarDictRust/pull/129)–[PR #131](https://github.com/palakpsheth/VarDictRust/pull/131)):

1. **OpenJDK 8 `TreeNode` Red-Black Bin Parity & Collision DoS Closure ([Issue #116](https://github.com/palakpsheth/VarDictRust/issues/116) `SEC-17b`, [PR #131](https://github.com/palakpsheth/VarDictRust/pull/131)):**
   - Ports OpenJDK 8 `java.util.HashMap.TreeNode` Red-Black treeification (`treeify`, `balanceInsertion`, `rotateLeft`, `rotateRight`, `moveRootToFront`, `getTreeNode`, single-pass `probe_tree_slot` / `putTreeVal`), deletion rebalancing (`removeTreeNode` entry-time pointer-topology untreeification, `balanceDeletion`, and 2-child interior link swapping), and `resize()` `TreeNode.split` (`UNTREEIFY_THRESHOLD = 6`) into `JavaHashMap<K, V>` (`crates/vardictrust-core/src/javamap.rs`).
   - Keeps `Node<K, V>` compact (`size_of::<Node<i32, i32>>() == 12`, `0` extra per-node bytes across `< 8`-collision biological cohorts) behind a cold `Option<Box<Vec<TreeLink>>>` sidecar, seals `JavaHash` with UTF-16 `String` ordering and signed `i32` spread-hash comparisons (`CWE-407` closure), enables `ORDER` assertions on `ops_treeify.txt` and `ops_getput_random.txt` (`regime=tree`), and expands the automated Cargo workspace test suite from `657` to **`664` tests**.
2. **Zensical Documentation Platform Migration ([Issue #123](https://github.com/palakpsheth/VarDictRust/issues/123), [PR #122](https://github.com/palakpsheth/VarDictRust/pull/122), [PR #129](https://github.com/palakpsheth/VarDictRust/pull/129)):**
   - Cuts over ReadTheDocs (`vardictrust.readthedocs.io`) and strict documentation CI from `mkdocs-material` (`mkdocs.yml`) to **Zensical** (`zensical.toml`, `zensical>=0.1.1,<0.2.0`), adding MathJax v3 initialization (`docs/javascripts/mathjax.js`), fence-aware Mermaid/GFM staging normalization in `harness/prepare_docs_site.py`, space-safe Zensical pre-commit/pre-push strict gates, pure-stdlib TOML `nav` validation in `check_release_consistency.py`, and 4-page Playwright Chromium DOM/MathJax/Mermaid/SVG UI verification (`harness/tests/test_docs_ui.py`).
3. **Release Supply-Chain, 6-Column SHA-256 Dataset Registry, Tag Ruleset Hardening & Dependency Updates ([Issue #116](https://github.com/palakpsheth/VarDictRust/issues/116) `SEC-05` / `SEC-14` / `SEC-12b`, [PR #110](https://github.com/palakpsheth/VarDictRust/pull/110)–[PR #112](https://github.com/palakpsheth/VarDictRust/pull/112), [PR #115](https://github.com/palakpsheth/VarDictRust/pull/115), [PR #117](https://github.com/palakpsheth/VarDictRust/pull/117), [PR #119](https://github.com/palakpsheth/VarDictRust/pull/119)–[PR #121](https://github.com/palakpsheth/VarDictRust/pull/121), [PR #124](https://github.com/palakpsheth/VarDictRust/pull/124), [PR #130](https://github.com/palakpsheth/VarDictRust/pull/130)):**
   - Replaces pipe-to-shell and unverified third-party toolchain installers in `.github/workflows/release.yml` with cached 4-architecture `cargo-dist v0.33.0` SHA-256 archive verification, `macos-15` `aarch64-apple-darwin` runner migration, SLSA v1.0 `resolvedDependencies[0]` alignment, `workflow_dispatch` recovery, and 6-job `step-security/harden-runner` audit; upgrades `harness/assets.tsv` to 6 columns with 40 verified SHA-256 digests, atomic `stage_verified_sha256`, and unconditional disk rehashing across `harness/fetch_data.sh` and slice stagers; enforces lockout-safe `refs/tags/v*` ruleset `24867690` in `harness/configure_github_repo.py`; replaces sub-second wall-clock test checks with deterministic step/probe bounds; and updates `noodles 0.119`, `flate2 1.1.11`, `lzma-rust2 0.24.0`, `log 0.4.35`, transitive Cargo crates, and GitHub Actions pins.
