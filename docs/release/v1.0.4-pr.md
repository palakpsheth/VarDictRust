## Overview

This pull request prepares and certifies **VarDictRust `v1.0.4`** off `main` (`e09b845`), consolidating the nine ungated parity-restoring fixes (`M-1` through `M-9`, [Issue #42](https://github.com/palakpsheth/VarDictRust/issues/42) / [PR #43](https://github.com/palakpsheth/VarDictRust/pull/43)) that achieved **89 / 89 MATCH** (`0` variant discrepancies across `11,227,154` called variants under float tolerance $\varepsilon = 10^{-6}$) against **VarDictJava v1.8.3** (commit `0886261`, Perl submodule `009e017`) across the 12-cell full-chromosome, full-exome, ultra-deep MRD (`2,000x`–`5,000x`), RNA-seq (`--splice`), CRAM twin, and amplicon panel validation sweep.

## Key Additions & Fixes in `v1.0.4`

### 1. Full-Corpus Parity-Restoring Engine Fixes (`Bug A`–`Bug H` & Adaptive Tiling, [Issue #42](https://github.com/palakpsheth/VarDictRust/issues/42), [PR #43](https://github.com/palakpsheth/VarDictRust/pull/43))
- **`Bug A` — Secondary `LoadedRegion` Selection in `CigarParser` ([`crates/vardictrust-core/src/cigar/parse.rs`](../../crates/vardictrust-core/src/cigar/parse.rs), [`src/reference.rs`](../../crates/vardictrust-core/src/reference.rs)):**
  - Selects the covering `(idx, lr)` in `reference.region_sequences` (`region_slice_for_span`) during structural-variant `partial_pipeline` re-parsing and spliced alignments (`CigarParser.java:181–193`, `257`).
- **`Bug B` — Reference `siteEnd` Lookahead Truncation ([`crates/vardictrust-core/src/reference.rs`](../../crates/vardictrust-core/src/reference.rs)):**
  - Truncates `bases` to `site_end = bases.len() - 17` after seeding `PendingSeedChunk` (`ReferenceResource.java:106–112`) so the trailing `SEED_1` (`17 bp`) lookahead is excluded from `region_sequences` and `reference_sequences` while remaining indexable by overlapping subsequent regions.
- **`Bug C` — CRAM Soft-Masked Base Normalization & Omitted `NM` Reconstruction ([`crates/vardictrust-core/src/bam.rs`](../../crates/vardictrust-core/src/bam.rs)):**
  - Uppercases CRAM reference-matching bases decoded against soft-masked lowercase FASTA contigs (`a/c/g/t/n` → `A/C/G/T/N`) and reconstructs omitted CRAM 3.0 (`store_nm=0`) `NM` edit distance tags via `compute_cram_nm` per SAMtags §1.5.
- **`Bug D` — Single-Sample `-f 0` Perl Falsy `0.02` Fallback vs `-f 0.0` Truthy Zero ([`crates/vardictrust/src/cli.rs`](../../crates/vardictrust/src/cli.rs), [`crates/vardictrust-core/src/output/vcf.rs`](../../crates/vardictrust-core/src/output/vcf.rs)):**
  - Replicates `var2vcf_valid.pl:21` (`my $Freq = $opt_f ? $opt_f : 0.02;`) via `valid_freq_threshold(config)` so `-f 0` (`"0"`) falls back to `0.02` while `-f 0.0` / `-f 0e0` preserve `0.0`.
- **`Bug E` — Somatic `v2nt.is_noise()` In-Place Coverage Propagation ([`crates/vardictrust-core/src/postprocess/somatic.rs`](../../crates/vardictrust-core/src/postprocess/somatic.rs)):**
  - Propagates `v2nt.is_noise()` in-place mutations (`total_pos_cov -= pos_coverage`) back into `v2.var_desc_to_variant` and `v2.variants` so subsequent tumor alleles at multi-allelic somatic loci observe the mutated `v2.variants[0]` (`SomaticPostProcessModule.java:172–186`).
- **`Bug F` — `<dupN>` $3'$ Flank `substr` Offset in `realignins` ([`crates/vardictrust-core/src/realign.rs`](../../crates/vardictrust-core/src/realign.rs)):**
  - Uses `start_idx = sv_flanking` (`50`) matching `VariationRealigner.java:744–746` (`substr(ins3, SVFLANK - ins3.length())`).
- **`Bug G` — $5'$ Candidate Deletion SV Post-Decrement Coverage Lookup ([`crates/vardictrust-core/src/sv.rs`](../../crates/vardictrust-core/src/sv.rs)):**
  - Queries `var_data.ref_coverage.get(&(p5_adj + 1))` after `p5--` in `find_sv` (`StructuralVariantsProcessor.java:732, 748`).
- **`Bug H` — Ultra-Deep Java `--fisher` (`FisherExact::new_java`) Parity ([`crates/vardictrust-core/src/stats/fisher.rs`](../../crates/vardictrust-core/src/stats/fisher.rs), [`src/output/table.rs`](../../crates/vardictrust-core/src/output/table.rs), [`src/output/vcf.rs`](../../crates/vardictrust-core/src/output/vcf.rs), [`src/lib.rs`](../../crates/vardictrust-core/src/lib.rs)):**
  - Emulates `FisherExact.java:72, 112, 129` in `--fisher` mode with 7-decimal `logdc` banker's rounding (`round_half_even(value, 7)`) and OpenJDK `DoubleStream.sum()` Kahan-Babuška compensated summation (`java_stream_sum`).
- **Adaptive Region Tiling (`<= 1 Mbp` Untiled / `> 1 Mbp` `100 kbp` Tiled, [`crates/vardictrust-core/src/lib.rs`](../../crates/vardictrust-core/src/lib.rs), [`crates/vardictrust/src/cli.rs`](../../crates/vardictrust/src/cli.rs)):**
  - Executes BED intervals `<= 1 Mbp` (`DEFAULT_UNTILED_SPAN_MAX`) as single untiled intervals matching VarDictJava while tiling multi-megabase intervals `> 1 Mbp` into `100 kbp` (`DEFAULT_TILE_SIZE`) windows to preserve `< 1.5 GiB` bounded WGS memory; raises `MAX_TILE_SIZE` to `500 Mbp`.
- **Mate-Window BAM Index Fallback ([`crates/vardictrust-core/src/lib.rs`](../../crates/vardictrust-core/src/lib.rs)):**
  - Updated `mate_window_query` to resolve BAM index paths via `bam::resolve_bam_index_path` (`foo.bam.bai` and `foo.bai` fallback), matching the primary BAM reader and preventing missed SV mate-window lookups when BAMs use `foo.bai` naming.
- **Golden Store `vardictcpp` Caching ([`harness/scale_bench.sh`](../../harness/scale_bench.sh), [`harness/run_integration.sh`](../../harness/run_integration.sh)):**
  - Routed all `vardictcpp` invocations in `scale_bench.sh` (`scale-th*`, `scale-R*`) and `run_integration.sh` through `harness/golden_store.sh`, with isolated `GOLDEN_STORE_DIR` in `harness/tests/test_scale_bench.sh` and strict enforcement in `harness/tests/test_golden_wiring.sh`.
