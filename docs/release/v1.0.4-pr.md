## Key Additions & Fixes in `v1.0.4`

### 1. Nine Ungated Parity-Restoring Fixes (`M-1`–`M-9`, [Issue #42](https://github.com/palakpsheth/VarDictRust/issues/42), [PR #43](https://github.com/palakpsheth/VarDictRust/pull/43))
- **`M-1` — Reference Chromosome $3'$ Buffer Extension ([`crates/vardictrust-core/src/reference.rs`](../../crates/vardictrust-core/src/reference.rs)):**
  - Extended `Reference::chr_lengths` end bounds by `+2 bp` (`end + 2`) matching `ReferenceResource.java:203`, preventing boundary k-mer seed truncation at region/tile edges.
- **`M-2` — OpenJDK `String.hashCode()` Seed Tie-Break ([`crates/vardictrust-core/src/reference.rs`](../../crates/vardictrust-core/src/reference.rs)):**
  - Added exact OpenJDK `String.hashCode()` tie-breaking (`s[0]*31^(n-1) + ...`) in `SeedMap::most_frequent_position` matching `VariationRealigner.java:1553–1563` when two k-mer seeds tie in cluster count.
- **`M-3` — Insertion Realignment Intermediate Mismatch Ratio ([`crates/vardictrust-core/src/realign.rs`](../../crates/vardictrust-core/src/realign.rs)):**
  - Updated `find_mms` to allow up to 3 intermediate mismatches provided `mm_cnt / mlen < 0.25`, matching `VariationRealigner.java:1966–1981`.
- **`M-4` — Insertion Trailing $3'$ Overhang Threshold ([`crates/vardictrust-core/src/cigar/parse.rs`](../../crates/vardictrust-core/src/cigar/parse.rs)):**
  - Ported `check_3prime_let_is_valid` (`< 4 bp` vs `< 3 bp` when `p >= 2`) matching `CigarParser.java:638–644`.
- **`M-5` — Coupled Indel `id_len` Extra-Length Guard ([`crates/vardictrust-core/src/cigar/parse.rs`](../../crates/vardictrust-core/src/cigar/parse.rs)):**
  - Ported the `id_len` extra-length check inside `parse_cigar` matching `CigarParser.java:784–787`.
- **`M-6` — Secondary Overlapping Region Selection ([`crates/vardictrust-core/src/cigar/parse.rs`](../../crates/vardictrust-core/src/cigar/parse.rs)):**
  - Ported `reg2` / `partial_HashMap` secondary region slice selection for reads spanning overlapping amplicon/targeted intervals (`CigarParser.java:257–274`).
- **`M-7` — Somatic `combine_analysis` Multi-Allele Rescue ([`crates/vardictrust-core/src/postprocess/somatic.rs`](../../crates/vardictrust-core/src/postprocess/somatic.rs)):**
  - Fixed `combine_analysis` to retain secondary Tumor/Normal allele matches when `number_of_processed_variation + 1 < v1.variants.len()`, matching `SomaticMode.java:361–531`.
- **`M-8` — RNA (`--splice`) $5'$ Soft-Clip Deletion Ceiling ([`crates/vardictrust-core/src/realign.rs`](../../crates/vardictrust-core/src/realign.rs)):**
  - Ported the `total_len < 5000` ceiling on $5'$ soft-clip deletion realignment in `--splice` mode matching `VariationRealigner.java:536`.
- **`M-9` — Zero VAF Threshold Validation (`-f 0` / `-f 0.0` / `-f 0e0`, [`crates/vardictrust/src/cli.rs`](../../crates/vardictrust/src/cli.rs)):**
  - Allowed `-f 0.0` (`>= 0.0` instead of `> 0.0`) matching VarDictJava CLI behavior.
