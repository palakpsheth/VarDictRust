## Key Additions & Improvements in `v1.0.1`

### 1. Advisory `vardictcpp` Third-Arm Reproducibility Harness
- Pinned **`vardictcpp 3 hc52dbad_0` (bioconda)** inside [`benchmarks/env/vardict-oracle.yml`](../../benchmarks/env/vardict-oracle.yml) alongside the Java oracle.
- Added [`harness/run_cpp.sh`](../../harness/run_cpp.sh), [`harness/staple_cpp_extra.sh`](../../harness/staple_cpp_extra.sh), and [`harness/tests/test_run_cpp.sh`](../../harness/tests/test_run_cpp.sh), wiring the advisory C++ arm into [`harness/compare.sh`](../../harness/compare.sh), [`harness/cram_twin.sh`](../../harness/cram_twin.sh), [`harness/scale_bench.sh`](../../harness/scale_bench.sh), [`harness/run_extended_coverage.sh`](../../harness/run_extended_coverage.sh), and [`harness/run_multimodal_slices.sh`](../../harness/run_multimodal_slices.sh).
- Enforced presence verification via `ev_cpp()` in [`harness/acceptance.sh`](../../harness/acceptance.sh) while keeping the release acceptance gate strictly `java == rust`. Known `vardictcpp` divergences are cataloged and normalized in [`docs/upstream-bugs.md`](../upstream-bugs.md#cpp-divergences).

### 2. Expanded 17-Modality Extended Parity & 230 Workspace Tests
- Expanded [`harness/run_extended_coverage.sh`](../../harness/run_extended_coverage.sh) from 9 to **17 clinical calling modalities** (`--crispr`, `-u`, `-A`, `--chimeric`, `-k 0`, `--fisher`, `-3`, `-O`, `-X`, `-c/-S/-E/-g`, `-M`, `--deldupvar`, `--DP ERR`), achieving `17/17 MATCH` (4,993 variants, 0 diffs).
- Added 19 CLI flag integration tests in [`crates/vardictrust/tests/flags.rs`](../../crates/vardictrust/tests/flags.rs), 2 CRAM decoder stack tests in [`crates/vardictrust-core/tests/cram_stack.rs`](../../crates/vardictrust-core/tests/cram_stack.rs), and package version verification in [`crates/vardictrust/tests/version.rs`](../../crates/vardictrust/tests/version.rs), expanding the workspace suite from 208 to **230 automated tests** (`189` core library + `2` CRAM stack + `13` CLI unit + `26` integration binary tests).
- Fixed multi-sample BAM header extraction on `-b "b1|b2"` in [`crates/vardictrust/src/main.rs`](../../crates/vardictrust/src/main.rs), added warning when `-N` omits the second sample name, and guarded `end == 0` in `StructuralVariantsProcessor::find_inv`.

### 3. Workspace-Version-Invariant Engine Fingerprinting & Recertified Evidence
- Updated [`harness/engine_fingerprint.sh`](../../harness/engine_fingerprint.sh) (`normalize_gate_blob()`) to canonicalize workspace-only SemVer fields across `Cargo.toml`, `crates/vardictrust/Cargo.toml`, and `Cargo.lock` prior to `git hash-object -t blob --stdin` (matching line 34's `if p.get("source")` filter).

- Recalibrated and certified whole-chromosome 1 scaling (`3.72×` 8-thread speedup, `1.45×` flat RSS ratio across a 25-fold span increase) and 4-target performance budgets (`30.1×` amplicon, `2.9×` SEQC2 exome, `2.0×` HG002, `1.6×` HG008) on the 14-core i7-13700H workstation.

### 4. Documentation Site, Wiki Sync & Release Engineering Runbook
