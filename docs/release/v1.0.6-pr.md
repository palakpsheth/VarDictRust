## Overview

This pull request prepares and certifies **VarDictRust `v1.0.6`** off `main` (`35b7b0c`), consolidating:
1. **Deep-Coverage Multi-Platform & Noise-Floor (`-f 0`) VarDictJava v1.8.3 Parity ([Issue #60](https://github.com/palakpsheth/VarDictRust/issues/60), [PR #61](https://github.com/palakpsheth/VarDictRust/pull/61), [PR #62](https://github.com/palakpsheth/VarDictRust/pull/62)):** Resolves 14 subtle upstream parity edge cases uncovered during the cross-platform `chr20` + Part B (`chr1`/`chr6`/`chr17`) audit across all 4 calling modes (`Simple`, `Somatic`, `Amplicon`, `Splicing`), 7 sequencing chemistries (`Illumina`, `PacBio HiFi`, `ONT`, `Element`, `Ultima`, `MGI`, `Roche SBX`), and both `-f 0.01` and `-f 0` (`-r 2` and `-r 1` noise floor).
2. **16 MiB Worker Thread Stack Resilience & Zero-Allocation Reference Seed Loading ([PR #61](https://github.com/palakpsheth/VarDictRust/pull/61), [PR #62](https://github.com/palakpsheth/VarDictRust/pull/62)):** Configures Rayon worker threads with a `16 MiB` stack (`WORKER_THREAD_STACK_BYTES`) to eliminate stack overflows during deep CRAM rANS/LZMA decompression and recursive structural variant realignment, and adds `reference::get_reference_with_chr_len` to eliminate per-window `HashMap` allocations.
3. **427-Test Workspace Suite & Mandatory Multi-Skill PR Review Gate ([PR #59](https://github.com/palakpsheth/VarDictRust/pull/59), [PR #61](https://github.com/palakpsheth/VarDictRust/pull/61), [PR #62](https://github.com/palakpsheth/VarDictRust/pull/62)):** Adds 11 new unit regression tests (`263` `vardictrust-core` library tests, `427` total workspace tests), updates in-tree Bioconda recipe metadata, and codifies the mandatory multi-skill PR review and Copilot thread-resolution gate in `AGENTS.md §15.8`.

## Key Additions, Optimizations & Fixes in `v1.0.6`

### 1. Deep-Coverage Multi-Platform & Noise-Floor (`-f 0`) Parity ([Issue #60](https://github.com/palakpsheth/VarDictRust/issues/60), [PR #61](https://github.com/palakpsheth/VarDictRust/pull/61), [PR #62](https://github.com/palakpsheth/VarDictRust/pull/62))
- **Multi-BAM Deduplication, Early-Break & Upfront Specification Validation ([`crates/vardictrust-core/src/bam.rs`](../../crates/vardictrust-core/src/bam.rs), [`src/lib.rs`](../../crates/vardictrust-core/src/lib.rs), [`src/realign.rs`](../../crates/vardictrust-core/src/realign.rs), [`src/sv.rs`](../../crates/vardictrust-core/src/sv.rs)):**
  - Resets per-BAM duplicate tracking via `RecordPreprocessor::reset_for_next_bam()` while preserving cumulative `total_reads`/`duplicate_reads` (`Scope.resetDuplicates`), replicates `BAMReader.hasMoreBams` (`if idx > 0 && !any_passed { break; }`) across colon-delimited multi-BAM inputs (`bam1:bam2`), and validates both tumor and normal BAM specifications upfront via `parse_colon_bams`.
- **Somatic BAM2 `splice` Set & `maxReadLength` Propagation ([`crates/vardictrust-core/src/lib.rs`](../../crates/vardictrust-core/src/lib.rs), [`src/postprocess/somatic.rs`](../../crates/vardictrust-core/src/postprocess/somatic.rs)):**
  - Seeds BAM2's `CigarParser` and `sv::find_all_sv` (`find_del_disc`) with BAM1's discovered `splice` set (`SomaticMode.java:104-122`), threads `&mut HashSet<String>` and `&mut max_read_length` across `combine_analysis` windows (`SomaticPostProcessModule.java:198-200, 303-311, 398-406`), and selects `max_af_variant` on 4-decimal banker-rounded `freq` (`SomaticPostProcessModule.java:118-127, 219-227`).
- **Pileup, Realignment, Structural Variants & VCF/Table Formatting ([`crates/vardictrust-core/src/cigar/parse.rs`](../../crates/vardictrust-core/src/cigar/parse.rs), [`src/variations/util.rs`](../../crates/vardictrust-core/src/variations/util.rs), [`src/realign.rs`](../../crates/vardictrust-core/src/realign.rs), [`src/sv.rs`](../../crates/vardictrust-core/src/sv.rs), [`src/tovars.rs`](../../crates/vardictrust-core/src/tovars.rs), [`src/postprocess/amplicon.rs`](../../crates/vardictrust-core/src/postprocess/amplicon.rs), [`src/output/table.rs`](../../crates/vardictrust-core/src/output/table.rs), [`src/output/vcf.rs`](../../crates/vardictrust-core/src/output/vcf.rs)):**
  - Updates `max_read_length` before the `0x800` supplementary-read return (`CigarParser.java:181-190`), counts reference `N` bases as mismatches with unconditional `offset` increment in `M`-after-`I` lookahead (`CigarParser.java:460-476`), uses signed `i32` loop bounds (`for k in 0..element_len`) in $3'$ soft-clip rescue (`CigarParser.java:1322-1457`), caches adaptor-cleared empty consensus sequences in `find_conseq` (`VariationUtils.java:136-148`), preserves `vref.cnt` in $5'$/$3'$ SV inversion branches (`StructuralVariantsProcessor.java:781-795, 922-936`), allows signed `next_var.fwd`/`rev` decrements in `ToVarsBuilder` (`ToVarsBuilder.java:337-340`), fixes amplicon null-row `tlamp`/`ncamp` and `good_variants` persistence (`AmpliconPostProcessModule.java:152-246`), canonicalizes `-0` in `round_half_even`, applies two-stage `1dp -> 0dp` `HALF_EVEN` rounding to paired `MQ` (`var2vcf_paired.pl`), evaluates VCF filters on rounded `HIAF`/`SN`/`MSI`/`SBF`, and emits `;CRISPR=` in single-sample VCF INFO when `-J` is enabled.
