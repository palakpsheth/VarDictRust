## Overview

This pull request prepares and certifies **VarDictRust `v1.0.7`** off `main` (`d5cae8a`), consolidating 16 pull requests ([PR #67](https://github.com/palakpsheth/VarDictRust/pull/67)–[PR #82](https://github.com/palakpsheth/VarDictRust/pull/82)) across the comprehensive A–N parity, robustness, and performance audit:

1. **VarDictJava v1.8.3 Oracle Statistical, CIGAR/SV, VCF & Formatting Parity ([PR #69](https://github.com/palakpsheth/VarDictRust/pull/69), [PR #74](https://github.com/palakpsheth/VarDictRust/pull/74), [PR #75](https://github.com/palakpsheth/VarDictRust/pull/75), [PR #76](https://github.com/palakpsheth/VarDictRust/pull/76), [PR #77](https://github.com/palakpsheth/VarDictRust/pull/77), [PR #78](https://github.com/palakpsheth/VarDictRust/pull/78), [PR #79](https://github.com/palakpsheth/VarDictRust/pull/79)):**
   - Replicates `HashMap.putVal` 9-node treeify trigger (`bin_len >= TREEIFY_THRESHOLD` in `JavaHashMap::insert`), `JavaHashMap::get_or_put_with` / `variations::get_or_put_vars`, `ToVarsBuilder::build_aligned_variants` empty-`Vars` insertion parity before `collect_reference_variants`, and `STRICT_VAR_ORDER=1` unsorted `.var` row-order verification (`crates/vardictrust-core/src/javamap.rs`, `src/variations/mod.rs`, `src/tovars.rs`, `src/realign.rs`) ([PR #74](https://github.com/palakpsheth/VarDictRust/pull/74)).
   - Replicates `inc_cnt` / insertion `tp` signed `i32` arithmetic and `realignlgins` signed `max_read_length - 10` bounds, excludes `=`/`X` from `get_soft_clipped_length`/`get_match_insertion_length`/`prepare_sv_structures_for_analysis` (`query_consumed_len` in `bam.rs`), scales `CigarModifier::modify_cigar`'s iteration bound with CIGAR operator count, and traverses `svffus`/`svrfus` in `is_best_sv_used` in OpenJDK `HashMap<String, List<Sclip>>` bucket order (`java_string_hash`, `java_hashmap_key_order` in `crates/vardictrust-core/src/cigar/modify.rs`, `src/cigar/parse.rs`, `src/realign.rs`, `src/javamap.rs`, `src/sv.rs`, `src/variations/mod.rs`) ([PR #75](https://github.com/palakpsheth/VarDictRust/pull/75)).
   - Replicates `DUPRATE=0` snapshot parity, `Utils.getRoundedValueToPrint` `"N."`/`"-0."` formatting (`push_java_rounded`), `FisherExact::get_odds_ratio` `java_double_to_string` scientific notation under `--fisher`, Apache Commons Math 3 `SaddlePointExpansion` / `HypergeometricDistribution` (`--fisher`), and R 4.x `fround` 5-decimal even-mantissa tie-break (`round_as_r`) (`crates/vardictrust-core/src/output/table.rs`, `src/output/vcf.rs`, `src/stats/fisher.rs`, `src/types.rs`, `src/variations/mod.rs`) ([PR #76](https://github.com/palakpsheth/VarDictRust/pull/76), [PR #77](https://github.com/palakpsheth/VarDictRust/pull/77)).
   - Replicates whole-stream VCF `$hash{chr}{start}` candidate accumulation and 4-decimal `round_half_even` AF winner selection across BED regions, Perl `sub reorder` chromosome ordering (`perl_reorder_chromosomes`), and `> 1 Mbp` multi-tile `max_read_length` pre-scan (`scan_multi_tile_max_read_lengths`) plus `-t` (`config.dedup`) boundary duplicate continuity (`crates/vardictrust-core/src/lib.rs`, `src/output/vcf.rs`, `src/cigar/modify.rs`) ([PR #78](https://github.com/palakpsheth/VarDictRust/pull/78)).
   - Replicates Commons-CLI `createNumber` (`parse_java_number_*`) & first-wins scalar options, `-F` `Integer.decode` & `samfilter_raw != "0"`, adaptor 6-mer `i + 6 < sequence.len()` & `ACGTacgt`-only complement (`realign::fill_adaptor_maps`), BED header/delimiter/4-col auto-detect (`java_split`, `detect_amplicon_bed`, `parse_amp_bed_from_reader` `java_hashmap_key_order`), `resolve_mode` precedence (`#378` / `--DP ERR`), amplicon segment `splice` chaining, and zero-coverage `-p` amplicon null-row formatting (`amplicon_38_into` / `amplicon_40_into`) (`crates/vardictrust/src/cli.rs`, `crates/vardictrust-core/src/realign.rs`, `src/regions.rs`, `src/postprocess/amplicon.rs`, `src/output/table.rs`) ([PR #69](https://github.com/palakpsheth/VarDictRust/pull/69), [PR #79](https://github.com/palakpsheth/VarDictRust/pull/79)).
2. **Bounded 512 MiB CRAM Reference Cache, Indexed CRAI Seek & Parallel Amplicon Mode ([Issue #63](https://github.com/palakpsheth/VarDictRust/issues/63), [PR #70](https://github.com/palakpsheth/VarDictRust/pull/70), [PR #81](https://github.com/palakpsheth/VarDictRust/pull/81), [PR #82](https://github.com/palakpsheth/VarDictRust/pull/82)):**
   - Adds a bounded `512 MiB` byte-budgeted reference cache (`DEFAULT_FASTA_CACHE_BUDGET_BYTES`) with active-`CramFeed` `Arc<ContigSlot>` pinning (`Arc::strong_count == 1` eviction), `RegistryDelegatingAdapter` handle pooling (`MAX_POOLED_FASTA_ADAPTERS = 8`), and `IndexedCrai` binary-searched CRAM slice lookup in `crates/vardictrust-core/src/bam.rs` ([PR #81](https://github.com/palakpsheth/VarDictRust/pull/81)).
   - Parallelizes `run_amplicon` across `(chrom, seg_idx)` groups via `runner::run_parallel` with deterministic input-order reassembly, switches `VariationMap::get_variation` to zero-allocation `RawEntryMut`, uses `FxBuildHasher` on `Vars::var_desc_to_variant`, boxes `VariationMap::sv: Option<Box<Sv>>`, adds an integer `u128` fast path in `types::round_half_even`, and eliminates hot-path allocations across `tovars.rs`, `sv.rs`, `util.rs`, and `variations/util.rs` ([Issue #63](https://github.com/palakpsheth/VarDictRust/issues/63), [PR #82](https://github.com/palakpsheth/VarDictRust/pull/82)).
   - Splits `_rjem_malloc_conf` by target OS (`background_thread:true` on Linux vs `background_thread:false,dirty_decay_ms:250,muzzy_decay_ms:0,narenas:8` on non-Linux via `MALLOC_CONF_LINUX_DEFAULT`, `MALLOC_CONF_NON_LINUX_DEFAULT`, `malloc_conf_bytes_for_target` in `crates/vardictrust/src/main.rs`) ([PR #70](https://github.com/palakpsheth/VarDictRust/pull/70)).
3. **Robustness Hardening, Harness Portability & 519-Test Workspace Suite ([PR #67](https://github.com/palakpsheth/VarDictRust/pull/67)–[PR #73](https://github.com/palakpsheth/VarDictRust/pull/73), [PR #80](https://github.com/palakpsheth/VarDictRust/pull/80)):**
   - Enforces `harness/lint_ratchet.sh` (forbidding production `unwrap`/`expect`/`panic!`/`unreachable!`), rejects truncated BGZF EOF (`UnexpectedEof`), validates CRAM/FASTA contig spans (`validate_cram_span`, `fetch_subsequence` past-end error) with 3' chromosome-end overhang padding (`CRAM_REF_OVERHANG_PAD = 65_536`), preserves raw `Vec<u8>` quality bytes for `Phred >= 95` (`normalize_cram_base`), enforces `i32` region coordinate bounds (`parse_int_with_commas` `<= i32::MAX`) and the 16 MiB worker stack floor (`WORKER_THREAD_STACK_FLOOR_BYTES` / `run_with_worker_stack` in `crates/vardictrust-core/src/runner.rs`), guards `x86_64` 80-bit `long double` oracle environments (`harness/run_oracle.sh`, `harness/compare.sh`, `harness/golden_store.py`), eliminates GNU-isms across harness scripts (`harness/lib/portable.sh`), expands the workspace test suite from `427` to **`519` tests**, and expands the harness diagnostic self-test suite to **`36/36` scripts** (`25` shell tests and `11` Python test suites).
