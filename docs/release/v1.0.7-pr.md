## Overview

This pull request prepares and certifies **VarDictRust `v1.0.7`** off `main` (`affb71e`), consolidating 16 pull requests ([PR #67](https://github.com/palakpsheth/VarDictRust/pull/67)–[PR #82](https://github.com/palakpsheth/VarDictRust/pull/82)) across the comprehensive A–N parity, robustness, and performance audit:

1. **VarDictJava v1.8.3 Oracle Statistical, CIGAR/SV, VCF & Formatting Parity ([PR #74](https://github.com/palakpsheth/VarDictRust/pull/74), [PR #75](https://github.com/palakpsheth/VarDictRust/pull/75), [PR #76](https://github.com/palakpsheth/VarDictRust/pull/76), [PR #77](https://github.com/palakpsheth/VarDictRust/pull/77), [PR #78](https://github.com/palakpsheth/VarDictRust/pull/78), [PR #79](https://github.com/palakpsheth/VarDictRust/pull/79)):**
   - Replicates `java.util.HashMap` treeify-vs-resize boundary (`< 64`), `TreeNode.split()` capacity check, and `Comparable` tie-break (`JavaHashMap<K: Eq + Hash + Ord>`) ([PR #74](https://github.com/palakpsheth/VarDictRust/pull/74)).
   - Ports `CigarModifier` double-insertion merge, `parse_cigar` deletion-to-mismatch conversion, `check_sv` inner-key iteration order, and `find_conseq` `maxCnt == 1` tie-break ([PR #75](https://github.com/palakpsheth/VarDictRust/pull/75)).
   - Replicates Java `DecimalFormat("0.0000")` / `R round()` `HALF_EVEN` formatting, `--fisher` vs non-`--fisher` p-value/odds-ratio precision, `qmean`/`pmean`/`m2f2` rounding, and single-sample `-k 0` realignment disabling ([PR #76](https://github.com/palakpsheth/VarDictRust/pull/76), [PR #77](https://github.com/palakpsheth/VarDictRust/pull/77)).
   - Propagates `max_read_length` across contiguous SimpleMode tile sub-windows (`SimpleMode.java:53, 81-116`) and aligns VCF `FILTER`, `<INV>` `END`, `-E`/`-C`, and CRISPR header/INFO parity ([PR #78](https://github.com/palakpsheth/VarDictRust/pull/78)).
   - Preserves amplicon pileup (`-p`) null-reference rows (`AmpliconPostProcessModule.java:152-186`) and hardens CLI flag/adapter validation (`-e`, `-d`, `-c`, `-S`, `-E`, `-s`, `-A`, `-T`, `--adaptor`) ([PR #79](https://github.com/palakpsheth/VarDictRust/pull/79)).
2. **Bounded Reference Cache (`--max-ref-cache-mb`), Zero-Copy Single-Ref CRAM Decode & Parallel Amplicon Mode ([Issue #63](https://github.com/palakpsheth/VarDictRust/issues/63), [PR #70](https://github.com/palakpsheth/VarDictRust/pull/70), [PR #81](https://github.com/palakpsheth/VarDictRust/pull/81), [PR #82](https://github.com/palakpsheth/VarDictRust/pull/82)):**
   - Adds a bounded FIFO reference cache (`--max-ref-cache-mb`, default `512 MiB`) with reference-counted active-pin tracking (`pin_count`) and delegated multi-ref CRAM sequence accounting (`delegated_bytes`), alongside zero-copy `SingleRefSequenceProvider` CRAM decoding and container-offset warmup skipping ([PR #81](https://github.com/palakpsheth/VarDictRust/pull/81)).
   - Parallelizes `run_amplicon` across `(chrom, seg_idx)` groups via `runner::run_parallel` with deterministic input-order reassembly, switches `VariationMap::get_variation` to zero-allocation `RawEntryMut`, replaces `format!("{:.N}")` float rounding with integer power-of-10 `round_half_even_f64_val`, and uses `SmallVec<[(usize, usize); 2]>` inside `find_35_match` ([Issue #63](https://github.com/palakpsheth/VarDictRust/issues/63), [PR #82](https://github.com/palakpsheth/VarDictRust/pull/82)).
   - Replaces invalid `muzzy_decay_ms` in macOS Mach-O `_rjem_malloc_conf` with `dirty_decay_ms:0,narenas:4` ([PR #70](https://github.com/palakpsheth/VarDictRust/pull/70)).
3. **Robustness Hardening, Harness Portability & 519-Test Workspace Suite ([PR #67](https://github.com/palakpsheth/VarDictRust/pull/67)–[PR #73](https://github.com/palakpsheth/VarDictRust/pull/73), [PR #80](https://github.com/palakpsheth/VarDictRust/pull/80)):**
   - Enforces `harness/lint_ratchet.sh` (forbidding production `unwrap`/`expect`/`panic!`/`unreachable!`), rejects truncated BGZF EOF (`UnexpectedEof`), guards `x86_64` 80-bit `long double` oracle environments (`harness/lib/oracle_platform.sh`), eliminates GNU-isms across harness scripts (`harness/lib/portable.sh`), and expands the workspace test suite from `427` to **`519` tests**.
